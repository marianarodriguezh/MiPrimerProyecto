# Mi Primer Proyecto GitHub
Este es mi primer repositorio.

Inicializar Git
git init
¿Qué hace?
Convierte la carpeta en un repositorio Git.

Agregar archivos
git add .
¿Qué hace?
Prepara todos los archivos para guardarlos.

Crear primer commit
git commit -m "Primer commit"
¿Qué hace?

Guarda una versión del proyecto.

Explicación completa
# Inicializa Git en la carpeta
git init
# Agrega todos los archivos
git add .
# Guarda una nueva versión
git commit -m "Primer commit"
